02 — SYSTEM ANATOMY

    
One recipe, five ingredients

    

      Every illustration is the same composable stack. Content editors only pick
      names from dropdowns — icon, theme, animation — and the renderer assembles the scene.
      No designer needed for a new department page.
    

    

      

        

        1 · THEME BACKDROP
        2 · EMBLEM (icon + shape + anim)
        3 · SATELLITE CHIP
        4 · PARTICLES
        5 · DASHED RING
      

      

        

          
1 Theme backdrop theme

          
Gradient pair + accent + soft tint + ink colour, chosen from 12 brand presets. Dot grid and soft blobs toggle via decor.

        

        

          
2 Emblem emblem.{icon, shape, anim}

          
The hero Phosphor icon on a disc — circle, blob, squircle or hex — with its own animation (e.g. pulse for cardiology).

        

        

          
3 Satellite chips satellites[]

          
Up to 4 floating white chips with secondary icons. Position is x/y percent so scenes stay composed at any viewport.

        

        

          
4 Particles & ring decor

          
Ambient dots and plus-marks (deterministic — same config, same layout, every render) plus an optional slowly-spinning dashed ring.

        

        

          
5 Animations anim

          

            float
            bob
            pulse
            breathe
            drift
            sway
            spin
            none

05 — CMS INTEGRATION SPEC

Ground rules

          
    
            
  • CMS stores strings and numbers only — icon names, enum selects, x/y percents. Never raw SVG.
    • 
            
  • Icon options come from a curated allow-list (~54 icons below) so editors can't break brand consistency.
    • 
            
  • Themes are presets, not free colours — the optional accent hex override is the escape hatch.
    • 
            
  • Positions are percent-based and sizes use container query units (cqw) — one config renders correctly from 320px to 1440px.
    • 
            
  • motion: 'off' and prefers-reduced-motion both freeze every animation.
    • 
            
  • New bespoke scenes (like rack) are dev-registered, then instantly selectable by editors.
    •
